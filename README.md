# Coursework Projects

Academic coursework projects kept as a record of university work outside the core cybersecurity, forensics, and investigation repositories.

## Current Areas

| Area | Contents |
|---|---|
| [Database](database/) | SQL Server setup, database assignments, and a Computer Shop Management System project |
| [Machine Learning](machine-learning/) | Data-preprocessing coursework, including KNN imputation |
| [Python Projects](python-projects/) | Standalone GUI/CLI applications: Event Planner Pro, File Extractor Tool, and Search Engine |

## Database Coursework

The database section contains practical SQL work completed in SQL Server Management Studio, including table creation, data insertion, basic queries, and a larger relational database project. The Computer Shop Management System includes schema definitions, sample data, CRUD examples, joins, stored procedures, and design diagrams.

## Machine Learning Coursework

The machine-learning section contains focused coursework on data preprocessing. The current project demonstrates KNN-based imputation for handling missing values with NumPy and scikit-learn.

## Python Coursework

The Python projects section preserves standalone applications developed during coursework:

- **Event Planner Pro** — Tkinter + SQLite event-booking manager with registration/login, bookings, calendar view, and statistics
- **File Extractor Tool** — ZIP/TAR archive extractor with path-traversal (zip-slip) protection
- **Search Engine** — Tkinter GUI for fuzzy full-text search using TF-IDF and fuzzy string matching

## Learning Focus

## Scope

This repository is primarily an academic record. It is intentionally separate from the portfolio's security-focused repositories so coursework can be preserved without making the main cybersecurity work harder to navigate.

The projects are presented as coursework and learning evidence rather than as production security tools.
