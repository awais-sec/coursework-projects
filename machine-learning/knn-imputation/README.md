# KNN Imputation

A short demo of filling in missing values in a NumPy array using
scikit-learn's `KNNImputer`, instead of a simple mean/median fill.

## Requirements

```
pip install numpy scikit-learn
```

## Run

```
python knn_imputation.py
```

`model-prediction-steps.txt` is a personal checklist I use for the general
data-preprocessing → model pipeline (cleaning, encoding, scaling, splitting,
balancing, feature engineering, dimensionality reduction, augmentation).
