# Python Projects

Standalone Python applications built during coursework, each with a GUI or
CLI front end and its own README with setup and usage instructions.

## Contents

- `event-planner-pro/` — a Tkinter + SQLite event-booking manager
  (registration/login, bookings, calendar view, stats)
- `file-extractor-tool/` — a ZIP/TAR archive extractor with path-traversal
  ("zip-slip") protection
- `search-engine/` — a Tkinter GUI for fuzzy full-text search inside a
  loaded text file, using TF-IDF and fuzzy string matching
